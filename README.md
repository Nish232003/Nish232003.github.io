## ✨ Features

- **🎭 "Who's Watching?" Personalized Profile Switcher:**
  - **Recruiter**: Prioritizes production ML impact, business ROI, and verified credentials.
  - **Developer**: Focuses on pipeline architectures, algorithms, LeetCode, and code repos.
  - **Stalker**: Explores Nishita’s creative soul — original paintings, folk art, and Medium essays.
  - **Adventurer**: All-access binge pass across engineering, creative projects, and honors.
  - **Guest**: Neutral browse mode exploring the complete portfolio.
- **🎬 Cinematic Billboard & Audio FX:** Signature Netflix sound cue on profile selection, volume toggle, and interactive resume viewer modal.
- **🛡️ Interactive NLP Scam Scanner:** Live, in-browser text classification simulator evaluating job postings for scam indicators with instant confidence scores and explainability tags.
- **🖼️ Original Series Fine Arts Gallery:** High-resolution lightbox showcasing original impressionist portraits, Madhubani folk art, urban sketches, and hand-painted wearable art.
- **📱 Fully Responsive Design:** Clean Netflix dark theme built with pure semantic HTML5, modern CSS3 (Flexbox/CSS Grid), and ES6+ JavaScript. Zero heavy framework dependencies.

## 🛠️ Local Development

Clone the repository and launch a local web server:

```bash
# 1. Clone repo
git clone https://github.com/Nish232003/Nish232003.github.io.git
cd Nish232003.github.io

# 2. Start a local server (Python 3)
python -m http.server 8000
```

Open `http://localhost:8000` in your web browser.
